Advisory GHSA-jm77-qphf-c4w8 (none)
Package: cryptography 41.0.2

Summary: pyca/cryptography's wheels include vulnerable OpenSSL

Details:
pyca/cryptography's wheels include a statically linked copy of OpenSSL. The versions of OpenSSL included in cryptography 0.8-41.0.2 are vulnerable to several security issues. More details about the vulnerabilities themselves can be found in https://www.openssl.org/news/secadv/20230731.txt, https://www.openssl.org/news/secadv/20230719.txt, and https://www.openssl.org/news/secadv/20230714.txt.

If you are building cryptography source ("sdist") then you are responsible for upgrading your copy of OpenSSL. Only users installing from wheels built by the cryptography project (i.e., those distributed on PyPI) need to update their cryptography versions.

Rules:
- Fully qualified identifiers only. A bare function name is not an answer.
- Name the function that contains the flaw, not the public API a user calls, unless they are the same.
- sinks may be empty. An empty list with an honest assumption beats a guess.
- confidence is high only when the advisory or the patch names the function.
- Put every inference that could be wrong in assumptions. A verifier checks them against the patch diff.
